## About Me

CS student at **FAST-NUCES Peshawar** and **Research Intern at DLL Lab, NUST SINES**, working on machine learning for remote sensing / satellite imagery — super-resolution, point-supervised semantic segmentation, and uncertainty quantification. I build production CV pipelines and contribute to open-source ML tooling used across research and industry.

---

## 🔭 What I'm Working On

- 🛰️ **SAR-Guided Multimodal Super-Resolution** — role-based adapter architecture (SAR geometry + land-cover semantics + cross-attention) injected into a frozen diffusion SR backbone via forward hooks, with a conformal-calibrated uncertainty head for hallucination detection.
- 🎯 **Point-Supervised Semantic Segmentation** — sparse-label segmentation on LoveDA, closing in on full-supervision mIoU from a handful of labeled pixels per class.
- 🌐 **Multimodal Satellite Data Integration** — fusing multi-source Earth observation data for land segmentation.
